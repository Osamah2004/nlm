# NLM (Node Level Manager)
## A level generator for PVZ2 Garden Endless

This repository contains the source code for NLM. For direct use of the application, visit this: https://nlm-pvz.netlify.app

---

## Local Development Setup

Clone the repository:
```bash
git clone https://github.com/Osamah2004/nlm.git
```
Navigate to the project directory:
```bash
cd nlm
```
Install npm dependencies:
```bash
npm run install
```
Run the project:
```bash
npm run dev
```
Navigate to this:
```bash
localhost:5173
```
